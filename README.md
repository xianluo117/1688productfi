# 1688 / Temu 产品管理系统

采集、整理和查看 1688、Temu 商品数据，支持多用户分组、历史记录、图片同款识别和跨平台找货源。

## 可以做什么

- **1688 商品管理**：采集上架信息和销量指标，按分组查看、筛选、排序，查询个人采集历史。
- **Temu 商品管理**：采集商品及云启相关数据，查看销量、价格、店铺和上架时间，收藏商品，导出收藏列表当前筛选结果为 XLSX。
- **图片处理**：下载商品图片，识别平台内同款，匹配跨平台商品。
- **1688 以图找图**：使用 Temu 商品图片查找 1688 商品，查看候选结果和官方图搜页面。
- **多用户管理**：管理员分配账号和个人采集令牌，按用户查看分组与历史。

图片相似度和以图找图需要管理员配置对应的外部服务，不是登录后即可直接使用的内置模型。

另外提供自有产品数据聚合接口，保存外部提交的批次、货号和颜色数据。**该模块目前没有网页操作入口**，接入方式见开发者文档。

## 开始使用

### 1. 获取账号

向管理员获取系统地址、用户名、密码和个人采集令牌。网页使用账号密码登录，采集脚本使用个人令牌上传，两者不能互相替代。

普通用户登录后选择 1688 或 Temu；管理员登录后进入控制台，选择对应产品管理模块。

### 2. 安装采集脚本

在浏览器安装 Tampermonkey，然后根据平台安装脚本：

- [1688 采集脚本](1688-listing-date-collector.user.js)
- [Temu 采集脚本](temu-product-collector.user.js)

安装或更新时确认 Tampermonkey 的权限提示，允许脚本连接系统后台。Temu 的云启相关字段需要页面中有相应数据。

### 3. 配置并采集

在脚本面板中填写：

| 配置 | 填写内容 |
|---|---|
| 后台地址 | 管理员提供的系统地址，例如 https://products.example.com，不加末尾斜杠 |
| 个人采集令牌 | 管理员创建用户或重置令牌时提供的值 |
| 分组 | 选择已有分组，或填写新的分组名称 |

在对应平台页面使用脚本采集并上传，再回到后台选择分组查看。新分组归属于令牌对应的用户。Temu 脚本也支持 CSV 导出。

### 4. 查看与整理商品

**1688**

1. 进入“1688 产品管理”，选择分组。
2. 按上架日期、上架天数、总笔数、总件数、每日笔数或最后采集时间筛选。
3. 调整排序和分页，打开商品详情查看采集历史。

**Temu**

1. 进入“Temu 产品管理”，选择全部产品、分组或收藏产品。
2. 使用筛选条件查看商品；列表默认隐藏广告，需要时开启“显示广告产品”。
3. 收藏或批量收藏商品。在“收藏产品”中点击“导出当前筛选 XLSX”。
4. 图搜完成后，列表展示 Top1 结果，详情可查看更多结果和 1688 官方图搜链接。

图搜候选结果不等于已确认货源；详情中的“显示货源”与外部图搜结果分开保存。

## 数据归属

- 分组、分组成员、采集批次和历史快照按用户区分；不同用户可以使用相同分组名称。
- 商品基础记录和最新指标全局共享。同一商品被其他用户再次上传后，当前指标也会更新。
- 管理员可以切换用户视角查看数据。
- 个人采集令牌仅在创建或重置时显示一次。重置后旧令牌立即失效；禁用账号会同时停止登录和采集授权。

## 常见问题

**没有账号或忘记密码怎么办？** 由管理员创建账号或重置密码。

**采集上传失败怎么办？** 核对后台地址、个人令牌和脚本连接权限；令牌失效时联系管理员重置。旧版全局采集令牌已不再支持。

**采集后找不到商品怎么办？** 检查脚本使用的账号令牌和分组，并清除列表筛选。Temu 商品还可能被默认广告筛选隐藏。

**没有图片、相似商品或图搜结果怎么办？** 这些结果依赖后台任务和外部服务，由管理员在图片下载、相似度检索或以图找图模块查看状态。

**如何自行部署？** 按[部署与管理员指南](docs/DEPLOYMENT.md)操作。默认仅允许服务器本机访问，远程使用需要调整监听地址或配置反向代理。
